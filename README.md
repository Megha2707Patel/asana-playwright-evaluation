# Playwright Data-Driven Automation Framework

This project contains a Playwright automation framework built using TypeScript and a data-driven testing approach.

## Objective

The framework validates task cards, columns, and tags for both Web Application and Mobile Application boards using reusable and scalable Playwright tests.

## Technologies Used

- Playwright
- TypeScript
- JSON Data-Driven Testing
